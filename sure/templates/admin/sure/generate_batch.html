QR codes in serial letters (Word)

The Excel contains a QR code in the cell of every case. It shows in Excel 365 and Excel 2021 or newer; LibreOffice and older Excel versions show #VALUE! instead.

Word does not take images over from Excel in a mail merge, so let Word draw the QR code from the URL:

  1. Select the downloaded Excel as the recipient list of the mail merge.
  2. Where the QR code should go, press Ctrl+F9 (Mac: Cmd+F9) and type between the braces: MERGEBARCODE Questionnaire_URL QR \q 3
  3. Press Alt+F9 (Mac: Option+F9) to leave the field code view and finish the merge as usual.

Use the field Case_ID to print the case number next to it.
